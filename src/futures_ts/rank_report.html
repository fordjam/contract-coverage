How to interpret these results

C1 is the earliest-expiring eligible outright in the latest definition snapshot available on each observation date. Ranks change as contracts expire. These are expiry ranks; continuous-series OI rolls use a separate schedule.

C3−C1 means the third expiry minus the first. The table maps both legs to actual symbols on the displayed date. Exchange-listed prices can use the opposite direction; the data retains that sign. A reverse quotation does not double volume.

Selections minimize the number of fixed relative labels for aggregate known activity in this historical window. They are in-sample results, with no transaction costs or leg acquisition costs. Required legs are shown separately. Daily coverage can fall below the aggregate target; no future coverage is guaranteed.

Outright and listed-calendar denominators are separate. Synthetic spread prices have no independent volume or OI and are excluded. Only explicitly identified, two-leg, one-for-one, same-root calendars enter this spread universe. Other structures, ambiguous definitions, unmapped IDs and missing observations are not counted as zero.

Cleared volume and OI use reference session dates. UTC-day traded volume is a separate measure; it is never mixed into a session denominator. Known activity coverage does not certify exchange-wide completeness. OI is summed instrument-days, not a single current OI snapshot. Unknown IDs cannot be attributed to individual roots; their archive-wide share is reported below.
