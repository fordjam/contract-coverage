# Code and data rights

The original project code is licensed under [0BSD](LICENSE). It may be used,
modified, distributed and sold without an attribution requirement. The warranty
disclaimer in the license applies.

Dependencies remain under their own licenses. No dependency is relicensed by
this project. The wheel contains original project code and templates, rather
than bundled vendor datasets or copies of the SDK. Review dependency notices
when distributing an assembled environment or application.

The validated dependencies declare these licenses:

| Dependency | Declared license |
| --- | --- |
| Polars | MIT |
| tzdata | Apache-2.0, with timezone-data notices supplied in its distribution |
| Databento Python client, optional | Apache-2.0 |
| databento-dbn, optional | Apache-2.0 |
| NumPy, optional | BSD-3-Clause and bundled-component licenses listed in its distribution |

Package installation preserves their distributed metadata/notices. Release
validation records exact installed versions; review those distributions when
changing dependencies rather than assuming this table is an exhaustive legal
inventory of their transitive or bundled components.

Market data, vendor identifiers, metadata and derived outputs are separate from
the software license. Users must have the rights needed for their data and use.
Examples and generated test fixtures are synthetic. Bloomberg support is a local
export mapping interface; no Bloomberg service, field semantics, endorsement or
redistribution rights are provided. Public release of real-data-derived results
requires review of the applicable dataset terms.
